## Featured projects

### [JARVIS — Personal AI Desktop Assistant](https://github.com/Austin-Figo/JARVIS)
A Windows desktop assistant combining voice interaction, multi-provider AI integration, local memory, and system automation.

**Stack:** Python · PySide6 · React · Vite · SQLite

### [EchoVault — Encrypted File Vault](https://github.com/Austin-Figo/EchoVault)
An academic proof of concept demonstrating AES-256-GCM file encryption and 3-of-5 Shamir Secret Sharing for threshold-based key recovery.

**Stack:** Java 21 · Spring Boot · React · H2/MySQL

### [Voice Gender Recognition](https://github.com/Austin-Figo/Voice-Gender-Recognition)
A Random Forest classification experiment using tabular acoustic voice measurements. The microphone inference path is documented as experimental until feature compatibility is validated.

**Stack:** Python · pandas · scikit-learn · librosa

### [Data Analytics Portfolio](https://github.com/Austin-Figo/AUSTINFIGOM_DA)
A growing workspace for reproducible analytics and machine-learning projects, including Crime Hotspot Prediction project documentation.

**Stack:** Python · SQL · Data Analysis
