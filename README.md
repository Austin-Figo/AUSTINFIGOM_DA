## Repository standards

Every completed project should include:

1. Problem statement and intended use
2. Dataset source, licence, schema, and limitations
3. Reproducible environment and setup instructions
4. Data cleaning and validation steps
5. Exploratory analysis and visualisations
6. Methods, assumptions, and leakage controls
7. Evaluation metrics with reproducible results
8. Findings, limitations, and future improvements
