# Austin Figo — Data Analytics Portfolio

A workspace for data analytics projects, reproducible analysis, and data-driven problem solving.

> **Current status:** Portfolio scaffold only. No completed datasets, notebooks, dashboards, or analysis projects are published in this repository yet.

## Planned project standard

Each published project will include:

1. **Business or research question** — the problem being investigated and why it matters.
2. **Dataset and provenance** — source, licence, scope, and known data-quality limitations.
3. **Data preparation** — cleaning, validation, transformation, and feature engineering.
4. **Exploratory analysis** — descriptive statistics and visualisations.
5. **Methods** — analytical techniques, assumptions, and reproducible implementation.
6. **Findings** — evidence-based results, limitations, and recommendations.
7. **Reproducibility** — environment requirements and instructions to reproduce the analysis.

## Planned structure

```text
AUSTINFIGOM_DA/
├── projects/
│   └── project-name/
│       ├── README.md
│       ├── data/          # small, permitted sample data only
│       ├── notebooks/
│       ├── src/
│       └── outputs/
├── requirements.txt
└── README.md
```

Large, private, or restricted datasets should not be committed. Link to the original source or provide a small synthetic sample where appropriate.

## Tools to be used as projects are added

Python, pandas, NumPy, SQL, Jupyter, and visualisation tools will be documented per project. Tools and results will only be listed once they are actually used.
